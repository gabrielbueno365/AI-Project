# Fase 5: Otimização, API FastAPI e Preparação Frontend - Especificação Técnica Revisada

## 1. Visão Geral

Esta fase final transforma o chatbot de uma aplicação de terminal para um serviço web completo, otimizado para performance e custo. O foco principal é:

A arquitetura MCP existente é fundamental, com o FastAPI atuando como o **Host MCP** principal, orquestrando as interações com os servidores MCP via MCP Clients.

### 2.2 Componentes Principais (Atualizado)

1.  **API RESTful (FastAPI)**: (`src/api/main.py`, `src/api/routers/*.py`) - O novo ponto de entrada principal. Define os endpoints HTTP (ex: `/chat`, `/upload`, `/memory_search`). **Atua como o Host MCP**, contendo a lógica de orquestração (Orchestrator da Fase 4) e gerenciando os MCP Clients.
2.  **Autenticação (API)**: (`src/auth/auth.py`) - Implementa autenticação baseada em token (ex: JWT) para proteger os endpoints da API.
3.  **Camada de Otimização**: (`src/optimization/*.py`) - Módulos para caching (ex: usando Redis ou `cachetools`), compressão de embeddings (PCA via `scikit-learn`), rate limiting (`slowapi`).
4.  **MCP Clients (no Host)**: (`src/clients/*.py`) - Mantidos e agora utilizados pelos handlers dos endpoints FastAPI para se comunicar com os servidores MCP. A inicialização e ciclo de vida deles precisam ser gerenciados pelo FastAPI (ex: via `lifespan` ou dependências).
5.  **Servidores MCP (Processos Separados)**: Todos os servidores desenvolvidos nas fases anteriores (`filesystem`, `rag`, `ollama`, `memory`, `metacognition`, `personality`, `embeddings`, `media`) e o `fetch` server (via npx/docker). São iniciados e gerenciados separadamente do processo da API FastAPI (podem ser processos locais, containers Docker, etc.).
6.  **Monitoramento/Logging**: (`src/logging/*.py`) - Integração com o logging do FastAPI, potencialmente enviando logs estruturados para um sistema centralizado e expondo métricas (Prometheus).

### 2.3 Fluxo de Dados (Exemplo: Chat via API)

1.  Frontend envia `POST /api/chat/message` com `{"message": "Resuma este documento"}` e anexa um arquivo ou URI.
2.  **Endpoint FastAPI (`api/routers/chat.py`)** recebe a requisição, valida o token JWT.
3.  Handler do endpoint FastAPI (atuando como Host MCP):
    *   Usa o `FilesystemClient` para chamar `tool: write_file` ou `tool: read_file` no `mcp-server-filesystem` (se for upload/URI).
    *   Usa o `RAGClient` para chamar `tool: index_uri` no `mcp-server-rag`.
    *   Usa o `RAGClient` para chamar `tool: semantic_search` (ou similar) para buscar contexto relevante.
    *   Usa o **Orchestrator/Router** para decidir como gerar a resposta (ex: chamar LLM via `LLMApiClient` ou `OllamaClient`).
    *   (Opcional) Usa o `PersonalityClient` para formatar a resposta.
    *   Usa o `MemoryClient` para salvar a interação.
4.  **Cache (Otimização)** é verificado/atualizado em etapas apropriadas (ex: cache de resposta LLM).
5.  Endpoint FastAPI retorna a resposta JSON para o Frontend.

```python
# src/optimization/caching.py
import redis.asyncio as aioredis
import json
import logging
from typing import Any, Optional
from core.config import settings

logger = logging.getLogger(__name__)
redis_pool = None

async def setup_cache():
    """Inicializa a conexão com o Redis."""
    global redis_pool
    if settings.USE_REDIS_CACHE and settings.REDIS_URL:
        try:
            redis_pool = aioredis.from_url(settings.REDIS_URL, decode_responses=True)
            await redis_pool.ping()
            logger.info("Conectado ao Redis para cache.")
        except Exception as e:
            logger.error(f"Falha ao conectar ao Redis: {e}. Cache desabilitado.")
            redis_pool = None
    else:
        logger.info("Cache Redis não configurado ou desabilitado.")

async def get_from_cache(key: str) -> Optional[Any]:
    """Busca um valor do cache Redis."""
    if not redis_pool: return None
    try:
        cached_val = await redis_pool.get(key)
        if cached_val:
            logger.debug(f"Cache HIT para key: {key}")
            return json.loads(cached_val)
        logger.debug(f"Cache MISS para key: {key}")
        return None
    except Exception as e:
        logger.error(f"Erro ao buscar do cache Redis ({key}): {e}")
        return None

async def set_in_cache(key: str, value: Any, expire_seconds: int = settings.CACHE_TTL):
    """Define um valor no cache Redis com expiração."""
    if not redis_pool: return
    try:
        await redis_pool.set(key, json.dumps(value), ex=expire_seconds)
        logger.debug(f"Valor setado no cache para key: {key} (expira em {expire_seconds}s)")
    except Exception as e:
        logger.error(f"Erro ao definir no cache Redis ({key}): {e}")
```

#### `compression.py`: Compressão de Embeddings (PCA)

```python
# src/optimization/compression.py
import numpy as np
from sklearn.decomposition import PCA
import pickle
import gzip
import logging
from typing import List, Optional

logger = logging.getLogger(__name__)

class EmbeddingCompressor:
    def __init__(self, target_dim: int = settings.EMBEDDING_COMPRESSION_DIM):
        self.pca: Optional[PCA] = None
        self.target_dim = target_dim
        self.is_fitted = False
        self.original_dim: Optional[int] = None
        # Carregar modelo PCA pré-treinado se existir
        self.load_model(settings.EMBEDDING_COMPRESSOR_PATH)

    def fit(self, embeddings: List[List[float]]):
        """Treina o modelo PCA com um conjunto de embeddings."""
        if not embeddings: return
        self.original_dim = len(embeddings[0])
        target = min(self.target_dim, len(embeddings), self.original_dim)
        if target < 1:
             logger.warning("Dimensão alvo inválida ou dados insuficientes para PCA.")
             return
        logger.info(f"Treinando PCA para reduzir de {self.original_dim} para {target} dimensões...")
        self.pca = PCA(n_components=target)
        self.pca.fit(np.array(embeddings))
        self.is_fitted = True
        logger.info(f"PCA treinado. Variância explicada: {sum(self.pca.explained_variance_ratio_):.4f}")
        self.save_model(settings.EMBEDDING_COMPRESSOR_PATH)

    def compress(self, embedding: List[float]) -> List[float]:
        """Comprime um único embedding."""
        if not self.is_fitted or not self.pca:
            # logger.warning("Compressor PCA não treinado, retornando original.")
            return embedding
        if len(embedding) != self.original_dim:
             logger.warning(f"Dimensão de embedding inesperada ({len(embedding)} vs {self.original_dim}). Retornando original.")
             return embedding

        compressed = self.pca.transform(np.array(embedding).reshape(1, -1))[0]
        # Aqui poderia adicionar Product Quantization (requer biblioteca como faiss)
        return compressed.tolist()

    def decompress(self, compressed_embedding: List[float]) -> List[float]:
        """Descomprime um embedding (aproximado)."""
        if not self.is_fitted or not self.pca: return compressed_embedding # Retorna como está se não treinado
        # Lógica de descompressão PQ viria aqui antes do inverse_transform
        reconstructed = self.pca.inverse_transform(np.array(compressed_embedding).reshape(1, -1))[0]
        return reconstructed.tolist()

    def save_model(self, filepath: str):
        if self.pca:
            try:
                with gzip.open(filepath, 'wb') as f:
                    pickle.dump({'pca': self.pca, 'original_dim': self.original_dim}, f)
                logger.info(f"Modelo PCA salvo em {filepath}")
            except Exception as e:
                logger.error(f"Erro ao salvar modelo PCA: {e}")

    def load_model(self, filepath: str):
        try:
            with gzip.open(filepath, 'rb') as f:
                data = pickle.load(f)
                self.pca = data['pca']
                self.original_dim = data['original_dim']
                self.is_fitted = True
                logger.info(f"Modelo PCA carregado de {filepath}")
        except FileNotFoundError:
            logger.info("Arquivo do modelo PCA não encontrado, será necessário treinar.")
        except Exception as e:
            logger.error(f"Erro ao carregar modelo PCA: {e}")

# Instância global ou gerenciada via dependência FastAPI
embedding_compressor = EmbeddingCompressor()
```

```python
# src/auth/auth.py (resumo)
from fastapi import Depends, HTTPException, status
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm
from jose import JWTError, jwt
from passlib.context import CryptContext
from datetime import datetime, timedelta, timezone
from typing import Optional, Dict
from pydantic import BaseModel

from core.config import settings
from .models import User, UserInDB, TokenData

pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/auth/token") # Ajuste o URL

def verify_password(plain_password, hashed_password):
    return pwd_context.verify(plain_password, hashed_password)

def get_password_hash(password):
    return pwd_context.hash(password)

# --- Simulação de Banco de Dados de Usuários ---
# Substitua por sua lógica real de banco de dados
FAKE_USERS_DB = {
    "testuser": {
        "username": "testuser",
        "full_name": "Test User",
        "email": "test@example.com",
        "hashed_password": get_password_hash("password"), # Hash da senha 'password'
        "disabled": False,
    }
}
def get_user_from_db(username: str) -> Optional[UserInDB]:
    if username in FAKE_USERS_DB:
        user_dict = FAKE_USERS_DB[username]
        return UserInDB(**user_dict)
    return None
# --- Fim da Simulação ---

def authenticate_user(username: str, password: str) -> Optional[UserInDB]:
    user = get_user_from_db(username)
    if not user or not verify_password(password, user.hashed_password):
        return None
    if user.disabled:
        return None
    return user

def create_access_token(data: dict, expires_delta: Optional[timedelta] = None):
    to_encode = data.copy()
    if expires_delta:
        expire = datetime.now(timezone.utc) + expires_delta
    else:
        expire = datetime.now(timezone.utc) + timedelta(minutes=settings.ACCESS_TOKEN_EXPIRE_MINUTES)
    to_encode.update({"exp": expire})
    encoded_jwt = jwt.encode(to_encode, settings.SECRET_KEY, algorithm=settings.ALGORITHM)
    return encoded_jwt

async def get_current_user(token: str = Depends(oauth2_scheme)) -> User:
    credentials_exception = HTTPException(
        status_code=status.HTTP_401_UNAUTHORIZED,
        detail="Could not validate credentials",
        headers={"WWW-Authenticate": "Bearer"},
    )
    try:
        payload = jwt.decode(token, settings.SECRET_KEY, algorithms=[settings.ALGORITHM])
        username: str = payload.get("sub")
        if username is None:
            raise credentials_exception
        token_data = TokenData(username=username)
    except JWTError:
        raise credentials_exception

    user = get_user_from_db(username=token_data.username)
    if user is None:
        raise credentials_exception
    # Retorna um modelo User simples, não UserInDB com hash
    return User(username=user.username, email=user.email, full_name=user.full_name)

# --- Router para /token ---
from fastapi import APIRouter
from .models import Token

router = APIRouter()

@router.post("/token", response_model=Token)
async def login_for_access_token(form_data: OAuth2PasswordRequestForm = Depends()):
    user = authenticate_user(form_data.username, form_data.password)
    if not user:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Incorrect username or password",
            headers={"WWW-Authenticate": "Bearer"},
        )
    access_token_expires = timedelta(minutes=settings.ACCESS_TOKEN_EXPIRE_MINUTES)
    access_token = create_access_token(
        data={"sub": user.username}, expires_delta=access_token_expires
    )
    return {"access_token": access_token, "token_type": "bearer"}
```

## 4. Plano de Implementação (Revisado)

### 4.1 Etapas de Desenvolvimento

1.  **Setup API FastAPI:** (2-3 dias) Criar estrutura `/src/api`, `main.py` básico, routers iniciais, configuração de dependências.
2.  **Autenticação:** (2-3 dias) Implementar JWT em `src/auth`, proteger endpoints.
3.  **Integrar Orchestrator/Clients:** (3-4 dias) Adaptar `Orchestrator` e `MCP Clients` para serem gerenciados pelo FastAPI (lifespan/dependências). Conectar endpoints aos métodos do Orchestrator.
4.  **Implementar Otimizações:**
    *   **Caching:** (2-3 dias) Integrar Redis/cachetools no `Orchestrator` ou `APIClient`.
    *   **Compressão Embeddings:** (2-3 dias) Implementar `EmbeddingCompressor`, integrá-lo onde embeddings são gerados/usados (provavelmente `mcp-server-rag` e `mcp-server-memory`). Treinar PCA offline.
5.  **Monitoramento e Logging:** (1-2 dias) Integrar Prometheus, refinar logging.
6.  **Documentação API:** (1-2 dias) Gerar e refinar documentação OpenAPI/Swagger.
7.  **Containerização (Opcional):** (2-3 dias) Criar Dockerfiles, `docker-compose.yml`.
8.  **Testes API e Fim-a-Fim:** (3-4 dias) Testar endpoints, fluxos completos via API, testes de carga básicos.

-   **Total**: ~18 - 27 dias de trabalho (Foco na API e otimizações).

## 5. Riscos e Mitigações (Atualizado)

| Risco                                | Probabilidade | Impacto | Mitigação                                                                        |
| :----------------------------------- | :------------ | :------ | :------------------------------------------------------------------------------- |
| Performance API sob Carga            | Média         | Alto    | Otimizações (cache, async), Testes de Carga, Escalonamento Horizontal (Docker). |
| Complexidade Gerenciamento Clientes MCP | Média         | Médio   | Usar `lifespan` do FastAPI, Injeção de Dependência clara.                     |
| Segurança da API Exposta             | Alta          | Crítico | Autenticação robusta, Rate Limiting, Validação Pydantic, HTTPS.                  |
| Overhead da Compressão/Descompressão | Baixa/Média   | Baixo   | Benchmarking, aplicar compressão apenas onde necessário (ex: armazenamento Qdrant). |
| Configuração Docker/Compose          | Média         | Médio   | Começar simples, documentar configuração de rede/volumes, usar exemplos.           |

## 6. Conclusão Revisada

A Fase 5 conclui o desenvolvimento do backend, transformando o sistema em uma **API FastAPI robusta e otimizada**, que atua como o **Host MCP** central. A arquitetura modular baseada nos servidores MCP das fases anteriores simplifica a criação da API, permitindo que o FastAPI se concentre na orquestração, segurança e exposição dos endpoints. As otimizações implementadas (cache, compressão) garantem performance e eficiência de custos. O resultado é um backend pronto para produção, bem documentado e preparado para ser consumido por um frontend web moderno.
